Namaz App

Android-приложение для расписания намазов.

Цель

Создать бесплатное Android-приложение с расписанием намазов по городам.

Основные функции

- Выбор города
- Расписание намазов
- Расписание на месяц
- Исламская дата
- Текущий намаз
- Следующий намаз
- Время поста
- Расчёт времени намазов
- Работа с API

Технологии

- Kotlin
- Android
- XML
- API
- GitHub

Статус

В разработке.
